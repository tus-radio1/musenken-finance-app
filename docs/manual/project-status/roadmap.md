### 整合性対応の追加マイグレーションは DB を先に適用

`20261025120000_soft_delete_member_rpc.sql`、`20261025121000_preserve_deleted_receipt_evidence.sql`、`20261025122000_receipt_cleanup_claims.sql` は追加のみの変更です。**DB を先に、またはアプリと同時にデプロイしてください。** 新しいアプリは部員削除 RPC と書類整理の競合防止 RPC を呼び出すため、アプリだけ先に出すと部員削除が失敗し、書類整理も安全側に停止します。

DB 適用 → アプリ公開 → 部員削除・書類作成失敗時の動作確認の順でリリースします。本番 DB デプロイは承認が必要です。上記の資金移動・監査閲覧の2マイグレーションは適用順を問わないままですが、今回の3件にはこの順序を適用します。
